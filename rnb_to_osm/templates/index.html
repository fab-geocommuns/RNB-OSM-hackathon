ℹ️ Documentation

Ces données sont le résultat d’une analyse comparative calculant automatiquement un taux de confiance : c'est le pourcentage de recouvrement des surfaces des bâtiments entre le référentiel du RNB et OSM. Seules les données considérées comme les plus fiables sont exportées : celles dont le taux de confiance est >70%.

Le détail de ce calcul est publié à l’adresse GitHub - fab-geocommuns/RNB-OSM-hackathon: Hackathon pour rapprocher les ID-RNBs de OSM

  • Définition d’un bâtiment dans OSM sur laquelle se base les données : FR:Key:ref:FR:RNB — OpenStreetMap Wiki
  • Définition d’un bâtiment dans le RNB : Référentiel National des Bâtiments

🛠️ Exploitation des données

  • Le tag ref:FR:RNB est ajouté aux bâtiments récupérés d'OSM. Il contient un ou plusieurs identifiant(s) RNB suggéré(s) à l’intégration dans OpenStreetMap. Il est possible de disposer de valeurs multiples, séparées par des ; pour un seul bâtiment OSM. L’identifiant RnB est pérenne pour chaque bâtiment.

N.B. : si un bâtiment est détruit et un nouveau est reconstruit au même emplacement, alors un nouvel ID est créé dans le RNB ; l’ancien ID continue d’exister mais prend le statut “détruit”. Cette information ne fait pas partie de l'export : elle est à retrouver dans les données du RNB.

  • Le tag diff:ref:FR:RNB : précision éventuelle de différence de modélisation entre les données RNB et OSM. Il prend la valeur splited si un bâtiment RNB correspond à plusieurs bâtiments OSM, il prend la valeur multiple si plusieurs bâtiments RNB correspondent à un seul bâtiment OSM.

Par exemple, les deux bâtiments identifiés sous les références S3HFGTCH14VF;C5NW96R48RQE dans le RNB correspond dans OSM à un seul bâtiment https://www.openstreetmap.org/way/190591890 avec le tag diff:ref:FR:RNB=multiple.
